
# Linux System Health Monitor

My first Bash scripting project for DevOps.

## Features
- Monitor CPU usage
- Monitor RAM usage
- Monitor disk usage
- Display warnings when usage is high
- Save system reports to a log file

## Technologies
- Linux (Ubuntu)
- Bash
- AWK

## How to Run

```bash
chmod +x monitor.sh
./monitor.sh
```

## Purpose
Learning Bash scripting, Linux system monitoring,
and DevOps automation.
